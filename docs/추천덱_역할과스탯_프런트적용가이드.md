# 추천덱 역할·스탯 표시 가이드

이번 변경은 프런트 표시용입니다. 기존 무장 기본 추천 배분과 백엔드 전투 계산은 그대로 유지합니다. **백엔드 재배포는 필요하지 않습니다.**

| 구분 | 값 |
|---|---|
| 백엔드/API 버전 | 기존 `0.6.4` |
| editor 데이터 버전 | 기존 `kr-editor-1b3c4ae82c1b432c` |
| 추천덱 스키마 | `2.1.0` |
| 표시 가이드 형식 | `1.0.0` |
| 추천덱 표시 자료 버전 | `kr-deck-guides-dbde4af5293c04d5` |

## 반영 범위

| 목록 | 전체 | 스탯 가이드 포함 | 역할 태그 포함 |
|---|---:|---:|---:|
| 기존 추천덱 | 128 | 62 | 6 |
| 한국 시즌3 참고 세팅 | 90 | 90 | 13 |
| 한국 시즌2 참고 편성 | 57 | 0 | 1 |

수량은 덱·세팅 단위입니다. 같은 가이드가 여러 전법 세팅에 연결될 수 있습니다. 역할이 명시되지 않은 무장은 빈 배열로 남겼습니다. 무력·지력·통솔 수치, 전후열, 장비 옵션만 보고 역할을 새로 지정하지 않습니다.

기존 가이드의 역할·배분 메모27개와 한국 시트의 세팅별 스탯·장비 문구를 사용했습니다. 원화궁의 육손은 한국 시즌3 원문에서 마법 딜러라고 명시한 내용으로 보강했습니다. 해당 메모는 연의 원소·손권·육손 세팅에만 연결했습니다. 다른 육손 조합으로 확대하지 않았습니다. 중국 자료를 한국 덱의 역할·배분으로 자동 가져오지 않습니다.

## 파일과 필드

| 목록 | 표시 가이드 위치 |
|---|---|
| 기존 추천덱 | `data/recommended-decks.json` → `templates[].display_guide` |
| 시즌3 참고 세팅 | `references/data/kr_s3_deck_references.json` → `variants[].display_guide` |
| 시즌2 참고 편성 | `references/data/kr_s2_deck_references.json` → `entries[].display_guide` |

세 파일 모두 `display_guide.members[]` 구조를 사용합니다. 무장 ID로 연결하세요. 시즌3 시트의 원문 순서를 실제 전후열로 사용하지 않습니다. 원문 이름이 등급·변형 때문에 특정 ID로 확정되지 않으면 `hero_id=null`입니다.

각 무장의 `entries[]`에는 다음 필드가 있습니다.

| 필드 | 의미 |
|---|---|
| `seasons` | 이 표시 메모를 사용할 한국 시즌 |
| `roles` | `damage` 딜러 / `tank` 탱커 / `healer` 힐러 / `support` 보조. 미기재는 `[]` |
| `role_note` | 역할 설명. 명시된 역할이 없으면 `null` |
| `action_note` | 역할과 구분한 행동 순서·운용 메모 |
| `stat_guide.text` | 화면에 표시할 스탯 가이드 원문 |
| `stat_guide.mode` | 단일 속성, 순서, 대안, 자유 문구의 구분 |
| `stat_guide.priority_groups` | 명시적으로 읽을 수 있는 배분 순서. 한 그룹 안의 속성은 우열을 붙이지 않음 |
| `stat_guide.mentioned_attributes` | 검색용 언급 속성. 우선순위가 아님 |
| `equipment_note`, `horse_note` | 해당 세팅의 장비·말 메모 |
| `source` | 가이드 제목과 식별자. 일부 시트 문구는 원문 링크 포함 |

가이드가 없는 무장은 `entries=[]`입니다. ‘역할 미기재’·‘배분 가이드 없음’으로 표시하거나 해당 영역을 숨기세요. 이를 무장 기본 추천 속성으로 대체해 덱별 가이드인 것처럼 표시하지 않습니다.

## 스탯 순서 표시

| mode | 예시 | 표시 방법 |
|---|---|---|
| `single_focus` | 지력 | 지력 위주 |
| `ordered` | 필요 선공을 맞춘 뒤 무력 | 선공 확보 → 무력. `text`도 함께 표시 |
| `alternatives` | 통솔/지력 | 통솔 / 지력. 통솔이 더 중요하다고 해석하지 않음 |
| `source_text` | 선공225, 나머지 무력, 통솔 최저 | 문구 그대로 표시 |

‘선공 약15점 후 무력’의15를 최종 선공 수치15로 변환하지 않습니다. ‘선공225’, ‘통솔221’, ‘강유 선공+1’, ‘지력1위’ 같은 문구도 이번 변경에서는 자동 배분·총 스탯 목표로 변환하지 않습니다. 수치·상대 순위·단위는 원문 문구로 보존합니다.

같은 장수3명이어도 세팅별 가이드가 다를 수 있습니다. 시즌3 자료에서는 선택한 `variant.id`의 가이드를 사용하세요. 다른 세팅의 스탯 문구를 합쳐 하나의 필수 조건으로 만들지 않습니다.

## SDK로 렌더링

새 `deck-display-guides.js`와 수정된 `recommended-decks.js`를 함께 교체합니다. 기존 메타 로더가 스키마2.0.0만 허용한다면2.1.0도 허용하도록 수정하세요.

```js
import {loadRecommendedDecks,displayGuideFor} from './recommended-decks.js';

const presets=await loadRecommendedDecks();
const template=presets.templates.find(t=>t.id==='sheet:a80_s1_chungui');
const guide=displayGuideFor(template,{season:3});

const rows=guide.members.map(m=>({
  heroId:m.hero_id,
  name:m.name,
  role:m.role_labels.join(' · ')||'역할 미기재',
  roleNotes:m.role_notes,
  actionNotes:m.action_notes,
  stats:m.stat_guides.map(s=>s.text),
  equipment:m.equipment_notes,
  horse:m.horse_notes
}));
// rows를 카드나 테이블에 표시합니다. 문구는 textContent로 출력하세요.
```

시즌3 참고덱도 같은 함수를 사용합니다.

```js
import {displayGuideFor} from './deck-display-guides.js';
const refs=await fetch('./references/data/kr_s3_deck_references.json',{
  cache:'no-cache'
}).then(r=>r.json());
const selectedSetup=refs.variants.find(v=>v.id===selectedVariantId);
const guide=displayGuideFor(selectedSetup,{season:3});
```

역할 필터와 가이드 문구 검색도 지원합니다.

```js
import {filterRecommendedDecks} from './recommended-decks.js';
const withHealer=filterRecommendedDecks(presets,{
  season:3,editor,role:'healer'
});
const speedGuides=filterRecommendedDecks(presets,{
  season:3,editor,query:'선공'
});
```

역할 필터는 명시된 태그가 있는 추천덱만 찾습니다. 결과가 적다는 이유로 나머지 덱에 해당 역할이 없다고 판단하지 않습니다.

## 시즌과 편성 수정

표시 함수에 현재 시즌을 전달하세요. 기존 배분 메모27개는 현재 메타에 시즌3용으로 들어 있던 자료이므로, 시즌1·2 화면에 자동 노출하지 않습니다. 시즌2 가후+힐러+제갈량 메모는 시즌2 참고 화면에만 표시됩니다.

`display_guide`는 추천덱 카드용 참고 정보입니다. 사용자가 장수·전법을 바꾼 편성의 역할을 자동 판정한 결과가 아닙니다. 수정 후에도 표시한다면 ‘원본 추천덱 가이드’라는 점을 구분하세요.

## 서버 요청과 배포

`display_guide`를 `army`나 `heroes[]` 안에 넣어 보내지 않습니다. 서버 입력 스키마는 표시용 필드를 받지 않습니다. 기존 `armyFromRecommendedDeck()`은 계속 `template.army`만 복원하므로 전투 요청과 공유 코드는 그대로 동작합니다.

이번 변경에서 다음 내용은 보존했습니다.

- 무장 기본 추천 속성과 추천 배분 기능
- 추천덱128개의 실제 편성·배분값·기존 TC1 공유 코드
- 한국 시즌별 editor 데이터와 API 명세
- 기존 장비·말 선택, 연의·투영 전법 기능
- 한국/중국 참고 자료의 시즌·출처 구분

프런트 메타 ZIP을 교체하고 사용 중인 SDK를 다시 빌드하면 됩니다. 백엔드나 FastAPI Cloud 설정은 변경하지 않습니다. 추천덱 표시 버전은 `recommendation_version`, 전투 입력 메타의 버전은 기존 `data_version`으로 구분합니다.
