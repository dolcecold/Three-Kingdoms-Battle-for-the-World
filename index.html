전투 서버 연결

배포한 백엔드 주소를 연결하면 현재 편성으로 전투를 계산할 수 있습니다. 편성과 공유 코드는 연결 없이도 사용할 수 있습니다.

연결이 되지 않나요?

백엔드가 실행 중인지 확인하고, 백엔드의 CORS_ORIGINS에 아래 주소를 추가하세요. 경로 없이 origin만 넣습니다.

GitHub Pages는 HTTPS이므로 API 주소도 HTTPS여야 합니다. 주소 끝에 /api나 /docs를 붙이지 않습니다.
